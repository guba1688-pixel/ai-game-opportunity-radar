# P001 手游发行新业务机会与立项决策台 — PRD

版本：0.2.0｜日期：2026-09-10

## 目标

把合规市场信号转成手游发行公司可执行的业务项目。管理者不读说明文档也能回答：做什么、适用地区/品类、产品从哪来、为何适合/不适合、投入多少、谁在何时做什么、达到什么继续、触发什么止损。

## 核心对象

- 业务机会：能形成发行、联运、服务或资产收益的项目。
- 内部能力工具：只提升决策或生产效率，不混入业务机会榜。
- 观察方向：与当前发行画像错位、现金或交付风险过高的方向。
- 公司能力画像：地区、品类、渠道、预算、团队能力、存量资产和回本偏好。

## 决策闭环

线索 → 初筛 → 7天取证 → 30天小测 → 扩大验证 → 正式立项/淘汰。每阶段都记录负责人、预算上限、完成与停止条件。评分核心是发行适配度，证据不足不直接立项。

## MVP 验收

1. 首屏显示立即测试、补证、暂缓/淘汰、轻中重资产、阶段与预算暴露。
2. 至少12个具体发行项目，另分内部工具和观察项，全部演示数据显著标记。
3. 支持地区、品类、资产、适配度、阶段、决策筛选。
4. 画像可编辑并持久化；新增/修改/删除、导出、审计和三角色权限继续有效。
5. KPI 示例明确不是跨国家/品类/平台/商业化模式的通用阈值。
