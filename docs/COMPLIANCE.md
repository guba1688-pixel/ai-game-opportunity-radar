# 合规边界

- 只接入无需登录即可访问且条款允许使用的公开数据或用户合法提供的数据。
- 不绕过登录、验证码、付费墙、robots/反爬限制，不采集私人或受限数据。
- 默认适配器使用演示种子；所有演示记录显示“演示数据”。
- 官方、第三方估算、模型推断、演示四类证据分开呈现；A-E 置信等级不可替代证据类型。
- 榜单不直接换算整月收入；估算必须保留口径、区间、假设、置信度和失效条件。
- 不自动执行投资、交易、广告投放或内容发布；输出仅供研究与验证决策。
- CPI、CTR、CVR、D1/D7/D30、付费率、ROAS、LTV 等演示阈值不得视为通用真理；正式值按国家、品类、平台和商业化模式配置。
- 老游戏再发行、源码/IP收购必须先核验完整授权链、地区期限、源码可构建性与历史数据口径。
- 配置中不写密钥；后续认证 API 应使用环境变量和最小权限。
