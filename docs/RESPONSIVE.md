# 显示器适配说明（v0.2.1）

网页按 CSS 逻辑视口适配，而不是直接按显示器物理英寸判断。macOS Retina 屏幕的物理像素会经过缩放，因此同一台 27 英寸显示器可能对应 1440、1728、1920 等不同逻辑宽度。

## 适配矩阵

- 21 英寸 / 紧凑桌面：1280–1359px，紧凑侧栏、两列 KPI、单列机会卡。
- 24 英寸 / 常规桌面：1360–1599px，流式页边距、双列机会卡、四列筛选区。
- 27 英寸 Mac / 5K 缩放：1600–1839px，双列机会卡、单行宽屏筛选区。
- 27/32 英寸全宽：1840–2199px，三列机会卡，充分使用工作区。
- 32 英寸 / 2560 逻辑宽：2200px 及以上，三列可读卡片、加大间距与筛选控件宽度。

移动端原有 760px 断点继续保留，并新增 430px 超窄屏保护。详情弹窗、阶段门和表格使用视口约束或内部滚动，不产生页面级横向滚动。
