# 数据模型 v2

- `company_profiles`：单例公司画像，含地区、品类、渠道、月度测试预算、素材/本地化/运营/数据/投放/渠道能力、存量产品和可接受回本月数。
- `opportunities`：兼容保留 v1 字段；新增 `opportunity_type`、地区/品类、产品来源、适配/不适配原因、负责人、验证阶段、决策状态、轻中重资产、7天/30天/扩大预算、当前阶段条件、证据缺口、KPI、继续/止损条件、回本逻辑、期限和全阶段门 JSON。
- `opportunity_scores`：11维发行适配度与总分；前四项结合公司画像。
- `schema_meta`：当前 schema 版本 `2`。
- `signals/sources/audit_logs`：保持 v1 结构与证据、去重、审计语义。

迁移只增加新表/新列/索引，不删除旧列、不清库。系统演示种子用 `seed_key` 幂等创建；仅首次迁移时补齐分类，后续启动不覆盖用户编辑。
