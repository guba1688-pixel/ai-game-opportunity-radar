# MVP 范围与里程碑（v0.2.0）

## 里程碑

- M0 基线与设计：PRD、数据模型、评分规则、合规边界。
- M1 数据底座：SQLite schema、迁移、种子、审计与去重。
- M2 采集层：统一适配器接口，AI 市场与游戏市场示例适配器。
- M3 机会引擎：机会 CRUD、11 维评分、L1-L4 与资产池分类。
- M4 管理台：看板、筛选、详情、编辑、采集、导出。
- M5 验收：单元/API 测试、持久化复验、浏览器主流程验证、交付记录。
- M6 发行决策升级：公司画像、12项发行机会、阶段门、轻中重资产、预算暴露与止损闭环。

## 数据边界

默认配置不联网，使用演示种子数据。配置公开 JSON URL 后，适配器只访问无需登录的 HTTP(S) 资源；响应仍按来源与证据类型入库。系统不声称示例数据是实时市场事实。

## 后续候选

定时调度、数据源健康告警、证据人工审核工作流、团队账号、细粒度数据范围、正式公开 API 连接器、相似机会聚类、可解释评分版本对比。
