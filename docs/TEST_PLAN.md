# 测试与验证计划

- 数据库：首次建库、种子标识、唯一去重、CRUD 持久化、审计日志。
- 评分：11 维边界、反向维度、L1-L4 边界、资产池。
- 采集：AI/游戏适配器、重复采集、演示标记、非法证据类型拒绝。
- API：健康检查、看板、筛选、详情、新增/修改/删除、权限、导出。
- UI：页面加载、筛选、机会详情、保存状态、采集、导出入口、演示数据标签、空状态。
- 回归：刷新后数据仍在；增删改后看板重算；viewer 无写权限；导出字段完整。
- v2：兼容迁移与备份、12项业务分类、画像持久化、种子幂等、六阶段主流程/淘汰归档、地区/品类/资产/适配度/阶段/决策筛选、预算暴露和浏览器详情闭环。
