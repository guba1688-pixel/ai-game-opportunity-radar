# 发行适配度与资产分级 v2

11项均为1-5分且越高越适配：现有渠道复用、投放能力复用、素材能力复用、本地化/运营复用、产品获取可行性、单位经济可验证性、低现金占用、回本速度、版权/合规清晰度、交付简洁度、战略协同。

前四项按“机会人工判断 50% + 公司画像对应能力 50%”四舍五入；总分为11项等权归一到100。分数必须结合 `score_rationale`、证据缺口与阶段门解释，不能替代授权、原始投放或结算数据。

资产级别按30天与扩大验证预算较高者：轻资产≤10万元；中资产≤50万元；重资产>50万元。旧 L1-L4 和 light/heavy 字段仅为 API 兼容，不作为 v2 首屏核心。

回本只按贡献现金：流水扣除平台/渠道分成、税费退款、持续买量和运营后，累计贡献现金覆盖全部投入。演示回本期与 KPI 不是行业真理，正式门槛必须按国家、品类、平台和商业化模式配置。
