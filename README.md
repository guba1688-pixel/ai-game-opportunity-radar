# 游戏市场情报台

P001 v0.7.0：把游戏市场资讯、机会雷达、人工情报和自动采集统一为老板决策台。综合首页优先展示临近截止、待决策事项、业务影响、负责人和建议动作；旧演示项目仍保留在雷达页用于展示决策流程。

## 统一面板

- 综合面板：近期真实资讯、优先机会、手动/自动采集数量和来源健康。
- 游戏市场雷达：按市场、行业、产品、渠道、商业、竞争、能力与风险视角分析机会。
- 游戏市场资讯：按关键词、证据类型和来源方式筛选。
- 手动提交资讯：写入 SQLite、自动去重、证据分级，并可直接关联机会。
- 自动监测/API：供榜单、公告、RSS 或内部采集脚本写入同一资讯池，接口说明见 `docs/INTELLIGENCE-API-v1.md`。
- DeepSeek：在“自动监测/API”页面配置 `deepseek-flash` 或 `deepseek-v4-pro` 并测试连接；密钥仅保存在服务器 `config/deepseek.json`（已忽略版本控制），也可用 `DEEPSEEK_API_KEY` 环境变量覆盖。
- 本周重点：按周一至周日读取本周新进入资讯池的证据，每周一自动换周；无新增时显示空状态，不循环冒充旧资讯。
- 老板决策：首页将事实转译为收入、上架、现金和增长影响，优先显示30天内截止事项，并为每条重点给出建议决策、负责人和原始来源。

## 多维视角

机会总览用于综合判断；市场视角看地区、品类、需求和证据；行业视角看产业链痛点与供给位置；产品视角看产品形态和 MVP；渠道视角看供给入口与获客路径；商业视角看收费、投入和回本；竞争视角看竞品与差异化；能力资产看可复用能力与缺口；风险视角优先展示风险、证据缺口与止损条件。角色选择不改变视角，只控制新增、编辑、导出和管理权限。

## 更新规则

左侧“更新规则中心”展示目标频次、每轮更新内容、事件触发条件、四层重叠判断、证据有效期和三档机会规模模型。规则源文件为 `config/update_rules.json`。当前没有真实公开数据源，因此系统明确保持“服务启动 + 人工更新”的真实状态；接入并验证真实源后才能启用定时执行。

## 数据来源与导入

“数据来源”页面区分演示数据、人工导入与真实在线数据。管理员可以导入不超过5MB的 CSV、JSON 或本地 HTML 快照；系统先备份 SQLite，再执行字段校验和精确去重，并返回接收、新增、重复和错误数量。每条导入资讯保留原始文件名、观察日期、采集/更新时间、新鲜度、证据等级和估算标记。计划连接器见 `config/source_connectors.json`，没有授权或密钥时不会假装采集成功。

## GitHub Pages 在线只读版

运行 `python scripts/export_github_pages.py` 会把当前数据库中的公开展示快照导出到 `docs/`。GitHub Pages 可直接从 `main /docs` 发布。在线版只用于浏览资讯和机会，不包含 SQLite 写入、DeepSeek 密钥、自动检测或管理操作；这些能力继续由本机或独立服务器后台提供。

全部为明确标注的演示数据，不代表真实市场规模、价格或 KPI。真实接入与权限说明见 `docs/COMPLIANCE.md`。
